Privacy policy

Command Center · last updated November 23, 2026

Command Center is a personal tool used only by its owner, on his own home computer. This page explains what it does with Google account data.

Who uses it

Only the owner. It is not offered to the public, and no one else can sign in to it.

What Google data it reads

  • Google Calendar (read-only): upcoming events, to mention in the daily briefing.
  • Gmail: reads messages the owner sends to himself (and a short list of approved family senders and school notices) to turn them into briefing items, and adds a label to messages it has already read out. It cannot send, delete or forward email.
  • Google Drive (read-only): downloads voice recordings from one folder the owner chose.
  • Calendars it creates itself: it can add events only to the two calendars it made. It cannot change any other calendar.

Where the data goes

  • Everything is stored on the owner's own computer. Nothing is uploaded to a server run by this project, because there isn't one.
  • Short summaries are written with an AI model (Anthropic's Claude) so the briefing reads naturally; only the text needed for that day's briefing is sent, under that provider's terms.
  • The finished briefing is saved as a private podcast episode in the owner's own Spotify account.
  • Google data is never sold, shared with anyone else, or used for advertising.

Google API Services User Data Policy

Command Center's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. The saved sign-in and all downloaded data live only on the owner's computer and are deleted from there.

Contact

Questions go to the developer contact listed on the app's Google sign-in screen.
